# ModelHub

ModelHub is a VicroCode model-route optimization SKILL for finding, pricing, testing, and integrating cost-effective model routes across 1,000+ global models.

## 中文简介

频繁切换中转站？累了吗？ModelHub 是 VicroCode 大模型线路智能优化技能，可自动搜索低价、优质、可用的模型线路，覆盖全球 1000+ 模型，支持模型选择、价格查询、路由对比、API Key 指引和 OpenAI/Anthropic/Gemini/图片/视频/Embedding 接入代码生成。

## English

Use ModelHub when you need to choose, compare, test, or integrate VicroCode API Center models across OpenAI-compatible, Anthropic, Gemini, image, video, and embedding endpoints.
